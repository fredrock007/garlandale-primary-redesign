===========================================================

Open index.html in Firefox or Chrome. All 11 HTML pages are linked from the menu.

Open Staff Login to enter the demo dashboard. Publish sample announcements,
events, document links and photo URLs. Changes are stored ONLY in that

The reset button restores the original demo data.

All calendar entries and documents shown by default are samples, not actual
school announcements. Documents without links are clearly marked unavailable.

The crest and school-life image are reference images drawn from user-supplied
screenshots of the school's public Facebook posts; permissions for publication
are NOT confirmed. Obtain school approval and proper learner-image permissions
before publishing the site publicly.

The website is NOT affiliated with or endorsed by Garlandale Primary School.
Verify contact details, official colours, fees, policies, staff, admissions
and school events with the school before any production launch.
