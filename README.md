# Garlandale Primary School — Independent Website Redesign Concept

A demonstration produced by **Reece Digital**. This is **not the official Garlandale Primary School website** and is not operated or endorsed by the school.

## Preview

Open `index.html` locally or enable GitHub Pages from `main` `/ (root)`.

## Features

Responsive school website, animated crest and page banners, academic and admissions information, interactive event calendar, animated document cards, gallery, and a demonstration staff dashboard.

## Demo staff login

The public demo displays its sample credentials. **This is not real authentication.** Local storage changes remain in the current browser and do not synchronise between visitors.

## Images and permissions

Learner photographs and third-party news photographs have been deliberately omitted from this public-ready preview. Original SVG concept artwork is used instead. The official crest is displayed solely to identify the school in the proposal. Any official adoption requires permission to use the crest and approved photographs.

## Publication

Publish only as an explicitly **independent concept**. Do not claim the demo staff login is secure or production-ready.
